# softChord 1.1

Desktop app for macOS (Apple Silicon and Intel) and Windows.

## What's new since 1.0.0

### Editing
- **View, then edit on purpose.** A song opens for viewing. Choose **Edit Chords…** or **Edit Text…** to change it, then **Save** or **Discard**. softChord asks before you leave a song, switch songs or quit with unsaved changes.
- The song number and title change in the song list only after you save.
- A transpose counts as a change too, until you transpose back.
- The selected chord gets a blue halo, and its letter a light blue box (on screen only, not in copies or prints).
- Up and Down no longer transpose the selected chord.
- Drag a rectangle to select several chords. Command-Z / Ctrl-Z undoes chord edits, transpose, trim, renumber and import.
- A chord moved or dragged onto a letter that already has a chord jumps over it. Editing lyrics no longer puts two chords on one letter.
- Text that is not a chord shows in red instead of `?`.
- **Reset transpose** button.

### Songs and songbooks
- Typing in the song filter keeps the open song open.
- Songbook format version 2 (one string per chord). Older songbooks are converted when opened, and the original is kept as a backup.
- Copy a song as an image from the Edit menu.
- Better import: non-UTF-8 text and ChordPro files, `{subtitle:}` and `{st:}`, Chorus / Припев title prefixes, trailing chord-only lines.
- Fixes: Undo after switching songs, Save As when the copy fails, pasting into a read-only songbook, appending a songbook's chords, and a crash at exit.

### Look
- New app icon.

## Install on macOS

1. Download `softChord-1.1-macos-arm64.dmg` for Apple Silicon (M1 and later) or `softChord-1.1-macos-x86_64.dmg` for Intel Macs.
2. Open the DMG and drag **softChord** onto **Applications**.
3. Open softChord from Applications. If macOS says it cannot check the app, open **System Settings → Privacy & Security** and click **Open Anyway**.

## Install on Windows

1. Download `softChord-1.1-windows.zip` and unzip it. It holds `softChord.exe` and `How to open softChord on Windows.txt`. (The bare `softChord-1.1-windows.exe` is also attached.)
2. Put `softChord.exe` where you want to keep it, for example a softChord folder in Documents. No installer or admin rights are needed. Double-clicking a `.songbook` file opens it with this copy.
3. softChord is not signed for Windows, so the first time Windows shows **"Windows protected your PC"**. Click **More info**, then **Run anyway**.
4. If the file is blocked after downloading: right-click `softChord.exe` → **Properties** → tick **Unblock** → **OK**.
